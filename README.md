## 🎓 How to Use

### Basic Usage (ClawKit Only)

```typescript
import { ClawKit } from '@clawkit/bnb';

const kit = new ClawKit(walletClient, {
  privateKey: process.env.PRIVATE_KEY
});

// Use modules normally
await kit.defi.swap({ from: 'BNB', to: 'USDT', amount: '0.1' });
```

### Advanced Usage (With Eidolon)

```typescript
import { ClawKit } from '@clawkit/bnb';
import { EidolonAgent } from '@clawkit/bnb/eidolon';

const kit = new ClawKit(walletClient, { privateKey });

// Create conscious agent
const agent = new EidolonAgent(
  kit.publicClient,
  kit.walletClient,
  {
    minConfidenceToTrade: 70,
    basePositionSize: 5,
    maxDrawdown: 10
  }
);

// Start autonomous operation
await agent.start();

// Agent now:
// - Adapts timing to volatility (Heart)
// - Explains all decisions (Transparency)
// - Learns from P&L (Brain)
// - Manages risk emotionally (Soul)
```

### Production Usage (With Tuned Params)
